# Contributing to CITG Fleet Management

Thank you for your interest in contributing to CITG Fleet Management!

## Getting Started

1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/your-feature-name`.
3. Make your changes.
4. Run tests (if applicable).
5. Open a Pull Request.

## Coding Standards

- Follow existing coding conventions.
- Keep commits focused.
- Ensure all tests pass.

## Reporting Issues

Please open an issue for bugs or feature requests. Include as much detail as possible.
